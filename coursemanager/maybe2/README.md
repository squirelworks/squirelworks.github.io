Source for the published lesson viewer.

- systemshell/shell.ts is the system books. The viewer calls openLesson and send.
- lessonshells/9e954d01.json is Logic Families. P0 carries the copyright text, jumps to P1, and the Acknowledge label.
- lessonshells/catalog.ts is the course list the viewer renders.

The app imports this folder. Change a lesson or a module here and the published viewer changes with it.
