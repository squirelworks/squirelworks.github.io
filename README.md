# squirelworks.github.io

The site opens on a Windows 95 desktop: [squirelworks.github.io](https://squirelworks.github.io/).

Click an icon.

| Icon | What it opens |
|---|---|
| NIDA ATT | The ATT master. A course is loaded from [NIDA_ATT](https://github.com/squirelworks/NIDA_ATT) `courses/`. |
| Foolcourse | The sample courses, loaded from [Foolcourse](https://github.com/squirelworks/Foolcourse). |
| Foolbook | The same books, or a file you choose. |
| Foolbook Editor | Pages, the page, and the object's script. Download writes an `.fbk`. |
| Byte Viewer | [squirelworks.github.io/byteviewer/](https://squirelworks.github.io/byteviewer/) |
| Repos | The squirelworks repositories. |
| Old viewers | The earlier course manager, still at [viewer4](coursemanager/viewer4/viewer.html). |
