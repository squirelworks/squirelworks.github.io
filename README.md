# squirelworks.github.io

Old archive of NIDA/Navy electronics courses (post-bootcamp ATT / electronics training) originally delivered as ToolBook books.

This GitHub Pages site preserves the converted course content (XML books under `coursemanager/viewer4/courses/` and related) so the historical lessons can still be viewed in a browser.

## Current viewer

- Entry: [coursemanager/coursemanager.html](coursemanager/coursemanager.html)
- Active viewer: [coursemanager/viewer4/viewer.html](coursemanager/viewer4/viewer.html)

## Related dedicated repositories

The experimental tools, unpackers, OpenScript work, and reverse-engineering notes that used to live here have been (or are being) moved to their own repos:

| Topic | Repo |
|-------|------|
| ToolBook 8 reverse-engineering notes | [tbworldview](https://github.com/squirelworks/tbworldview) |
| OPTLOADER unpacker for ToolBook NE binaries | [toolbookunpacker](https://github.com/squirelworks/toolbookunpacker) |
| OpenScript analysis / decoder | [openscript_analysis](https://github.com/squirelworks/openscript_analysis) |
| Modern ToolBook-compatible viewer | [Foolbook](https://github.com/squirelworks/Foolbook) |
| Course system built on Foolbook | [Foolcourse](https://github.com/squirelworks/Foolcourse) |
| Hosting ToolBook 8 runtime | [TBpipeline](https://github.com/squirelworks/TBpipeline) |
| NIDA shell/system books | [NIDA_ATT](https://github.com/squirelworks/NIDA_ATT) |

## Pruning status

Superseded experimental directories are being removed in favor of the dedicated repos above. Course archive content is kept.
