# Graal / Seihai / LinuxMan2 Documentation

Binned from the Graal recon project (artifacts) on 2026-10-29.

Unique folder for the Squirrel OS/2 desktop scanner to pick up and generate an icon for.

## Contents

- **LinuxMan2**: Man pages, architecture, notes on Graal tools (GANI, editor, RC, generators, gif2mng).
- **GraalShop**: GANI editor documentation (domain, sprites, animation, movie).
- **GraalEditor**: Level editor (Thinstall, BOARD/LINK/SIGN/CHEST/NPC/BADDY).
- **RemoteControl**: RC client protocol and architecture.
- **TerrainGenerator**: Plasma terrain, GRMAP001 / GLEVNW01.
- **gif2mng**: GIF to PNG/MNG converter.
- **DungeonGenerator / LevelGen**: Related generators.
- **Seihai**: Documentation for the Seihai client/world.
- **GraalLStory**: Novel chapters walking the LinuxMan2 hall.

Full local sources remain in the project artifacts. This folder holds the primary Markdown and HTML for browsing on the desktop.
