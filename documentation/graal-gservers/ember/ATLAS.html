1.3.x is one translation unit plus helpers. gs2emu is the first rewrite: one process, many worlds via servers.txt, per-player encryption generation, RC and NPC-Server as extra player types. Phoenix ships that binary. Ash rewrites the same protocol in Python.

2. Process blueprint

flowchart LR subgraph process["gserver2 / ashserver process"] M[main] --> ST[servers.txt] ST --> W1[TServer world A] ST --> W2[TServer world B] W1 --> L1[listen serverport] W1 --> LS[listserver TCP 14900] W1 --> SM[select / poll sockets] SM --> P1[TPlayer client] SM --> P2[TPlayer RC] SM --> P3[TPlayer NPC-Server] end C[v2 client] --> L1 RC[RC.exe] --> L1 NS[npcserver] --> L1 LS --> LIST["listserver.graal.in"]
main.cpp (gs2emu) / ashserver.main
  1. Parse argv (--server override exists).
  2. Load servers.txt, spawn one TServer per server_N.
  3. gs2emu: each world is a boost::thread. Ash: one thread per world accept loop + player threads.
  4. Signal SIGINT/TERM tears the list down and saves accounts.
