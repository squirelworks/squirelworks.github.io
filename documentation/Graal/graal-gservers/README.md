# Graal gServers Documentation

This folder contains the Ember architecture atlas and the GServerStory series for the Graal Online gserver reverse-engineering and rewrite work.

## Ember
Architecture atlas: lineage, architecture, protocol, algorithms, and blueprints for the gserver engine.

See `ember/ATLAS.html` or the numbered markdown files starting at `ember/00-index.md`.

## GServerStory
Narrative walkthrough of the gserver sources, chapters 1–39, plus command index.

Start at `gserverstory/00-series.md`.

These were generated as part of the Graal gserver analysis project.
