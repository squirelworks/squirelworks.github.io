# Chapter 39 — The Words for the Doors

The book was the building. The index is the list of words the building answers to, and it is the last page.

Part 1 was how a socket becomes a world. A morning that reads `servers.txt` and keeps serving the wrong name. A costume of shifts and generations. A login that is a token, a signature, and a staff bit that walks through a ban. A body of props, and a board of 64 by 64. A clerk that is a newline socket. A chair that is a person with a bit. A process that is a third species. Two houses, Phoenix and Ash, built from the same dump. A way to read the sources, and a way to start looking at a binary that has lost its names.

Part 2 was the rooms that spine named. A map that lies about its edges. An account that is a person between sessions, saved when it feels like it. A weapon that is a file, newlines turned into `0xA7`. A fight the server relays and a drop it sometimes rolls. A mouth, with a jail and a filter. A queue that coalesces until a file is too large to be polite. Signs, horses, items, the things a level keeps for a few seconds. A guild that is a substring in a file, and a group key that dies when the instance does. The version cuts, stood in a row. The residue in the 2.4 binary, which was a label and a typo and a path. One unnamed function, found by the sentence it still says. And the line: the server does not run the script.

Part 3 was the five things those rooms had only named. The baddy and its roll of twelve. The link that is not a door unless the file exists. Three bans. A plugin hook that can eat a save. The chair's catalog, which is shorter than the chair.

Part 4 stayed on the server's side of the line. The string it builds, the split, the 12255-byte clip. The query switch, and the missing break. The old interpreter in `npcs.cpp`, which had `if` and `while` and was taken out. The three scripts the packages actually ship.

Part 5 named the script side of doors already open. A level NPC, a weapon, a class. The dash the client reads and the server does not. The origin as an address, a weapon always passing `0, 0` and its own name. The other window, which belongs to the process and keeps `scripttime`.

Chapter 34 was who steps the half after the marker. The client. The Bible says so, and the shelf does not contain the stepper.

---

The index is what those doors are called when a script says them.

`artifacts/gserverstory/command-index.md` is three lists held up to each other. The classic `commands.rtf`. Shakaraja's 2008 guide. The Graal Bible's function pages, which are the only ones that say which side a verb lives on. A name in two of them is firmer than a name in one.

Read it as a glossary for the chapters, not as a new engine. `say2` is chapter 19, and `#b` is why the newlines were replaced. `toweapons` is chapter 15. `triggeraction` at `0, 0` is chapter 8 and chapter 37. `hitplayer` is chapter 16. `move` and its option bits are chapter 31's NPC move. `timeout` and `settimer` are the same arm, and they are not a packet. Item indexes 0 through 5 are the baddy roll. Baddy mode 6 is the swamp shot, mode 9 is dead. The 13 KB cap and the 12255-byte warning are the same limit. The 64 KB cap is the file send before 2.14. `timevar` is the five-second counter the server already computed.

What the index will not do is step a script. A name in the RTF and the Bible is a verb the language agreed on. A name only in the guide is a 2008 claim. A kingdom verb is a different game. The gserver stores the string, splits on the marker, and forwards the trigger. The client, or a process you start beside the world, is who wakes on the event.

That is the building, and that is the list of words. The next packet is still the client's.
