# Graal v2.05 Client Reference

Documentation binned for the squirelworks.github.io desktop.

## Contents

- This folder holds cleaned notes and the reference manual for the Graal v2.05 rev2 client (image base 00400000, FileVersion 2.0.5.2, token GNW03081 / CLVER_2_052).

- Full cleaned corpus lives in the companion repository [squirelworks/Graal_analysis](https://github.com/squirelworks/Graal_analysis).

- Key areas: formats (GLEVNW01, GR-V1, tile walk, sign text), protocol (session opcodes, framing, list host), GS1 commands, client internals (config, rendering, offline training), and the 24-page reference manual.

## Reference Manual

The PDF `Graal_v205_Reference_Manual.pdf` covers binary layout, architecture, GS1, session, list, tile, sign, config, rendering, and offline behavior. Tables are laid out for duplex printing.

## Boundary

Notes here and in Graal_analysis contain no raw decompile material, addresses, or binary dumps. They are derived from public sources, observed behavior, and cleaned summaries.
