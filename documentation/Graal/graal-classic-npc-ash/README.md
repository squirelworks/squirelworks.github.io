# Graal Classic NPC Architecture Reference

Architecture documentation, blueprints, flowcharts, algorithms, and pseudocode for a large Graal Online / Classic NPC + level dump (~1520 unique script bodies, 6275 placements).

**Source:** tricxta / Phoenix / Meh / Ultimate NPC Pack community dump analysis (package date 2026-10-14).

This folder is placed under `/documentation/` on the Squirrel OS/2 desktop so the scanner can generate a desktop icon for it.

## Contents

- `INDEX.md` — pack map, classification counts, reading guide
- `00-runtime/` — client NPC runtime model, event dictionary, state and image IDs
- `01-larency/` — HUD, inventory, shop, lockpicking, ranger baddy
- `02-phoenix/` — quests, dialogue, baddies, minigames, farm, weapons
- `03-meh/` — weapons and smartbaddy AI
- `04-unp/` — Ultimate NPC Pack minigames and player houses
- `05-standalone/` — balloon fight, tower defense, scrollers, FX, RPG, etc.
- `PACKAGE-README.md` — description of the original full reference package

The full extract (unique bodies, documented packs, catalogs) was archived separately. These files document control flow and algorithms without reprinting script bodies.
