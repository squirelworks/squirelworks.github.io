# GraalLStory

## Chapter XI — Said Again

This chapter opens no door. The doors are already open. What follows is the hall said once, in the order the foot would need it, without a new signature and without a new test.

The world did not begin as a picture. `pics1.png` is 2048 by 512, sixteen-pixel cells, 128 across and 32 down, 4096 ids. A level stores the index. `AA` is tile 0. `//` is tile 4095. A room is 64 by 64 tiles, a text file that should open `GLEVNW01`, a `BOARD` line of two base64 characters a tile, landing at `levelTiles[x + y * 64]`. The layer index is parsed and not used. Step off the edge and you have not entered a larger field. You have hit a `LINK`.

The picture does not judge the walk. A second table does. Wall if the type byte is at least 20, or if the foot is outside the board. Water if the byte is exactly 11. Of the 4096 ids, 3061 are walls in that table, 47 are water, 988 are walkable. Chair, bed, swamp, and lava are stored and, in the SDL client, not consulted. Official Graal.exe around 2.05 had a different mask. Two masks can both be true of Graal and false of each other.

Three writers share `GLEVNW01` and do not share a board. The client and the dungeon generator speak base64 runs. Terrain writes 64 rows of tile 0, one hundred and twenty-eight `A` characters, and hides the land in a 9 by 9 `HEIGHTS` block, to be read only if a type-5 tiledef the file does not contain has already been believed. The editor writes `BOARD 0` as 64 lines of 64 decimal indices and does not require the signature. `GRMAP001` splits the same way. Dungeon sets `GENERATED` to the bottom-right level name. Terrain sets `GENERATED 1` as a flag. Levelgen reads an eight-bit picture, lets water cover mountains, does not draw pure grass, and sews links at 61 only on levels it created. Do not feed one writer to another loader and expect a board.

The shop is not a shop. `GraalShop.exe` edits a `.gani`. `GANI0001` is sprite mode: a sprite table, a header, `ANI` until `ANIEND`. `GANI0002` is movie mode: actors inside `MOVIE`. Switching modes deletes the other timeline. A missing signature is accepted as the sprite dialect. The parser lowercases keywords. The writer emits uppercase and padded columns. Without `SINGLEDIRECTION`, a frame is four rows: up, left, down, right. That is body `200` `201` `202` `203`. Seihai numbers south as 0. These rows do not. The wait counter starts at 1. `SCRIPT` until `SCRIPTEND` is copied and not run. `DEFAULTHEAD` is `head19.png`. `DEFAULTBODY` is `body.png`. Sprite 0 in `def.gani` is the shadow.

The desk does not stand on a tile. Remote Control is the Delphi predecessor of `RC2_2.05.exe`. Twenty-five forms. The console is `gvar_004BB0F0`. Two sockets, both `TGraalClient`: `+0x38c` the game line, `+0x390` the NPC line. A send to nil does nothing. NPC login is type 3, payload starting `NCL11012`. The codec is the classic text one: an id plus `0x20`, a length plus `0x20`, the first line of a session carrying the XOR increment. Even modes are XOR-ed with the Borland generator, state `0x04A80B38`. A player begins as 3 hearts, 5 arrows, 10 bombs, `sword1.gif`, `head0.gif`, `body.png`, and `onlinestartlocal.graal`, until the property stream says otherwise. Property 10 is the gani. The file browser will not write unless the rights string contains `w`.

The converter does not write a world. Fewer than two frames become a PNG. Two or more become an MNG. Color type is always 3. Transparency is a `tRNS` hole, not an alpha channel. `-b` snaps the palette onto seven body slots and forces the hole to index 2, which is also the default green, `0, 132, 0`. A channel within 32 counts as a match. The tile walk never sees that index.

The editor in the client folder is not the editor. `LoaderFlags` is an offset, `0xFC94E`. The magic is `0x82D0B188`. The first block is the Thinstall runtime. Two codecs: `0xDE` for the stub, `0xD7` for the virtual filesystem. Unpacked, it is version 2.3.1.1, form `TAdventure`, unit `UAdventureEditor`. It opens `*.graal` and `*.nw` as the same text. Heights are a `TLevelHeights` overlay, not a second board. A chest points at a sign by index. Deleting the chest does not delete the sign. The same GANI classes as the shop are linked in.

The drawer is five `GOBJSET01` files, 288 stamps, 6948 cells. The SDL fork does not open the folder. The first stamp is `ACAD` over `ASAT`: ids 2, 3, 18, 19, types 20, 20, 22, 22, a wall only because the table says so. The name Bush dies in the placing. PushStone and PullStone are different pictures, not a rule. A lava picture is not type 12. Snow is the same shapes and different ids, not a recolor.

The foot is one point. The step is `16 * 0.30` pixels. Directions in that loop are 0 up, 1 left, 2 down, 3 right. The test is the feet, thirty-two across and forty-four down, divided by sixteen. There is no slide and no water slowdown. `isOnWater` exists and is exported to V8. The keyboard loop does not call it. The blit cuts a sheet as sixteen columns. Official `pics1.png` is 128. Drop it in and every id past 15 is mis-cut. The chest coordinates believe the classic sheet. The blit does not. Baddy id 0 is left null because the real client treats it as broken.

Seihai still opens the old line and then disagrees. It writes `SH-V1` and `GLEVAS01`. It accepts `GR-V1` and `GLEVNW01` as aliases, name and magic both required. Its grid is the same 64 by 64 and a different vocabulary. Water is id 2 and solid. A bush is id 5 and can be cut. Zero faces south. Six hit points draw as three hearts. The body is four corners. X is tried, then Y, so a slide works. Mara sells one heart for 40 rupees and then has nothing left. That counter is a counter. The other shop was not.

One keypress is all of this and none of it. The loader keeps an id. The table says 20 or it does not. The gani, if the step is allowed, advances a row. The desk can list the person and cannot push the foot. The package has to be opened before the program is the program. The generators share a word and not a file. Index 2 is the color that is not there.

A signature is a doorplate. It is not a promise that the room was furnished by the same hand. The grass can wait. The player believes they walked on it up to a wall. They walked on an index, up to a byte.
