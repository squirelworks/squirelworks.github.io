# GraalLStory

A novel of the platform, written from the install that is still on disk.

The official tree lives at `artifacts/graal`. The long notes live in LinuxMan 2. This book does not invent a second protocol. Where a sentence names a signature, a size, or a test, it is naming something the reconstruction already measured.

## The book

1. [The First Line](chapter-01-the-first-line.md) — the client folder, the 4096 tile ids, the 64 by 64 board, and why three writers can share a signature and still not share a level.
2. [The Shop That Does Not Sell](chapter-02-the-shop-that-does-not-sell.md) — GraalShop as a GANI editor: `GANI0001` sprite mode, `GANI0002` movie mode, four direction rows, and a script the shop copies and does not run.
3. [The Desk With Two Sockets](chapter-03-the-desk-with-two-sockets.md) — Remote Control: RC socket and NPC socket, the classic text codec, player property streams, and a file browser that will not write without `w`.
4. [The Hands That Do Not Share a Board](chapter-04-the-hands-that-do-not-share-a-board.md) — terrain, dungeon, and levelgen: three writers of `GLEVNW01` and `GRMAP001` that do not emit the same file.
5. [The Color That Is Not There](chapter-05-the-color-that-is-not-there.md) — gif2mng: one frame becomes a PNG, two or more an MNG, and `-b` forces the hole to index 2.
6. [The Package That Is Not the Editor](chapter-06-the-package-that-is-not-the-editor.md) — GraalEditor as a Thinstall package, then the unpacked Delphi image that paints a decimal `BOARD 0` and does not require `GLEVNW01`.
7. [The Drawer That Forgets Its Name](chapter-07-the-drawer-that-forgets-its-name.md) — five `GOBJSET01` files, 288 stamps, and a bush that is a wall only because the type table says so.
8. [The Foot](chapter-08-the-foot.md) — the SDL fork: one point for the feet, a wall if the type byte is at least 20, and a blit that does not cut `pics1.png` the official way.
9. [One Keypress](chapter-09-one-keypress.md) — the arrow followed back through every signature. The step is one. The writers are not.
10. [The Zero That Faces South](chapter-10-the-zero-that-faces-south.md) — Seihai still opens `GLEVNW01` and `GR-V1`, writes `GLEVAS01` and `SH-V1`, and numbers south as 0. Water is solid. A bush is id 5.
11. [Said Again](chapter-11-said-again.md) — the hall in one pass. No new signature. No new test.
12. [The Hall, Repainted](chapter-12-the-hall-repainted.md) — the same doors, seen as sheets, slots, and blits. The pixel is still not the law.

Later rooms, not yet written: Mara's counter, which sells one heart for 40 rupees and remembers the flag.
