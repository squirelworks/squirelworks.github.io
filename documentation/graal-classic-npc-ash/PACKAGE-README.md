# Seihai Game Development — Graal Classic NPC Reference Package

**Package date:** 2026-10-14  
**Source:** Graal Online / Classic NPC + level dump analysis  
**Purpose:** Drop-in reference for the new Seihai project. Unpack this zip into your project directory so the team can analyze Classic systems, port algorithms, and understand event-driven client NPC patterns.

This is a cleaned, catalogued, and architecturally documented extract of a large Classic Graal NPC dump (~2,700+ files, hundreds of levels). It is **not** a playable server or full level set. It is the scripted NPC intelligence extracted and documented.

Full package structure and reading order are described in the original README. The architecture sections in this folder are the primary reference for porting control flow and algorithms.
