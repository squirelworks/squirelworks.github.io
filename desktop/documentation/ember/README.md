# Ember documentation

Ember is a top-down walker for the old Enigma level archive. It is a React page plus three modules. It does not run NPC scripts, fight baddies, or open a socket. You walk, you read what is nearby, and doors load the next file.

| Document | What it covers |
|---|---|
| [Framework](framework.md) | Host stack, files Ember needs, what it deliberately does not do |
| [Architecture](architecture.md) | Modules, the live state, and who owns each job |
| [Levels](levels.md) | `.graal` and `.nw` bytes, tiles, links, signs, the catalog |
| [Runtime](runtime.md) | Boot, the frame, doors, the camera, input, save |
| [Diagrams](diagrams.md) | The same system as flowcharts and maps |
